
# Math Expression Solver

A small, focused library and CLI for parsing and evaluating mathematical expressions with correct operator precedence, parentheses, unary operators, numeric support, and common math functions. Designed to be embedded in other projects or used as a command-line tool.

Live demo (Streamlit Community Cloud): https://aicalculator.streamlit.app/

Key points
- Parses and evaluates arithmetic expressions (+, -, *, /, ^), parentheses, and unary operators
- Supports floats and integers and common math functions (where implemented)
- Can be used as a library or via a simple CLI
